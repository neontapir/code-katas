# code-katas

A place for me to store various implementations of code katas I've done, mostly for me to look at later.

You'll find:

<dl>
  <dt>99 Bottles of Beer
    <dd>The "99 Bottles" kata - refactoring and TDD practice
  <dt>Advent of Code 2022
    <dd>Solutions to Advent of Code 2022 challenges
  <dt>Big Number
    <dd>A kata about working with large numbers
  <dt>Bowling Game
    <dd>The classic kata from Uncle Bob Martin, in several languages and approaches
  <dt>Commit Derby
    <dd>A TDD exercise focused on atomic commits and incremental development
  <dt>Decorator Dojo
    <dd>A coding exercise I've used to teach the Decorator pattern
  <dt>Diamond Kata
    <dd>The Diamond kata - generating ASCII diamonds with various approaches
  <dt>Gilded Rose
    <dd>The famous legacy code kata. Use the `pristine` tag to get to the beginning
  <dt>Prime Factors
    <dd>A kata about finding the prime factors of a number
  <dt>Robocode
    <dd>An implementation of a Robocode robot in F#.
    It's terrible, but it was a learning experience for me.
  <dt>Secret Santa
    <dd>Take an input file of names and pair people
  <dt>TDD Workshop
    <dd>A collection of katas and exercises for learning TDD, including FizzBuzz, Roman Numerals, Banking Kata, and more
  <dt>Train Reservation Kata
    <dd>A kata about building a train reservation system
</dl>

Each folder has implementations in a variety of languages. The Bowling Game kata is the most varied.
